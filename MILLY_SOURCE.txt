## 1. Problem Statement

Post-Traumatic Stress Disorder (PTSD) affects millions of trauma survivors worldwide. Individuals living with PTSD frequently struggle with sudden intrusive flashbacks, debilitating nightmares, hypervigilance, and unexpected sensory triggers. While psychotherapy (such as EMDR and Cognitive Processing Therapy) is highly effective, survivors frequently experience acute distress outside clinic hoursâ€”at home, late at night, or in crowded public environments.

Most general-purpose AI conversational agents are ill-suited for trauma support:
- They can hallucinate unverified medical advice.
- They lack domain-bounded emotional grounding.
- They depend on external cloud APIs that transmit sensitive thoughts to third parties.
- They lack architectural separation between conversational dialogue and deeply confidential private journal notes.

---

## 2. Objective

**MILLY** is an open-source, domain-specific AI support companion designed specifically around PTSD trauma recovery and emotional regulation.

Key objectives:
1. Provide instant, evidence-informed trauma psychoeducation and somatic grounding.
2. Accurately categorize user intents across 15 PTSD-specific domains.
3. Detect user emotional states across 7 affective categories.
4. Intercept acute crisis / self-harm language before response generation.
5. Retrieve curated, evidence-based coping literature using local TF-IDF cosine similarity without external paid LLMs.
6. Enforce a strict architectural privacy wall between the AI dialogue engine and the user's PIN-locked digital journal.

## 3. Technology Stack

- **Backend:** Java 21+ / Java 24, Spring Boot 3.3.4 (REST Controllers, Spring Data JPA, HikariCP)
- **Database:** SQLite embedded database (`milly.db`) with Hibernate Community Dialect
- **NLP & Machine Learning Engine:** Native Java Machine Learning:
  - Text Normalization & N-gram Tokenizer
  - TF-IDF Vectorizer with smooth IDF & L2-normalization
  - Multinomial Logistic Regression (Softmax Regression) trained with Gradient Descent and L2-regularization
  - Evaluation metric calculation (Accuracy, Precision, Recall, Macro F1-score)
- **Information Retrieval:** Local TF-IDF Cosine Similarity index over curated PTSD knowledge base
- **Frontend:** React 19, Vite, Tailwind CSS v4, Lucide Icons, Recharts

### C. Mathematical Formulation
- **Smooth Inverse Document Frequency (IDF):**
  $$\text{IDF}(t) = \ln\left(\frac{1 + N}{1 + \text{DF}(t)}\right) + 1$$
- **L2-Normalized TF-IDF Feature Vector:**
  $$v_i = \frac{\text{TF-IDF}_i}{\sqrt{\sum_{j} \text{TF-IDF}_j^2}}$$
- **Multinomial Softmax Probabilities:**
  $$P(y = k \mid x) = \frac{\exp(w_k^T x + b_k)}{\sum_{m=0}^{K-1} \exp(w_m^T x + b_m)}$$
- **Loss Function with L2-Regularization:**
  $$J(W, b) = -\frac{1}{N} \sum_{i=1}^N \ln P(y^{(i)} \mid x^{(i)}) + \frac{\lambda}{2} \sum_{k} \sum_{j} W_{k, j}^2$$

Due to Maven's design, elements are inherited from the parent POM to the project POM.
While most of the inheritance is fine, it also inherits unwanted elements like `<license>` and `<developers>` from the parent.

If you manually switch to a different parent and actually want the inheritance, you need to remove those overrides.

package com.milly.backend.ai.model;

import java.io.Serializable;

/**
 * Encapsulates standard Machine Learning evaluation metrics:
 * Accuracy, Macro-averaged Precision, Recall, and F1 Score.
 */
public class ModelMetrics implements Serializable {

    private static final long serialVersionUID = 1L;

    private final double accuracy;
    private final double precision;
    private final double recall;
    private final double f1Score;
    private final int totalSamples;
    private final Map<String, Double> classF1Scores;

    public ModelMetrics(double accuracy, double precision, double recall, double f1Score,
                        int totalSamples, Map<String, Double> classF1Scores) {
        this.accuracy = accuracy;
        this.precision = precision;
        this.recall = recall;
        this.f1Score = f1Score;
        this.totalSamples = totalSamples;
        this.classF1Scores = classF1Scores;
    }

    public double getAccuracy() {
        return accuracy;
    }

    public double getPrecision() {
        return precision;
    }

    public double getRecall() {
        return recall;
    }

    public double getF1Score() {
        return f1Score;
    }

    public int getTotalSamples() {
        return totalSamples;
    }

    public Map<String, Double> getClassF1Scores() {
        return classF1Scores;
    }

    @Override
    public String toString() {
        StringBuilder sb = new StringBuilder();
        sb.append(String.format("Evaluation Metrics (Total Samples: %d):%n", totalSamples));
        sb.append(String.format(" - Accuracy:  %.4f (%.2f%%)%n", accuracy, accuracy * 100));
        sb.append(String.format(" - Precision: %.4f%n", precision));
        sb.append(String.format(" - Recall:    %.4f%n", recall));
        sb.append(String.format(" - F1-Score:  %.4f%n", f1Score));
        if (classF1Scores != null && !classF1Scores.isEmpty()) {
            sb.append("Per-Class F1 Scores:\n");
            for (Map.Entry<String, Double> entry : classF1Scores.entrySet()) {
                sb.append(String.format("   %-22s : %.4f%n", entry.getKey(), entry.getValue()));
            }
        }
        return sb.toString();
    }
}

package com.milly.backend.ai.nlp;

import java.io.BufferedReader;
import java.io.InputStream;
import java.io.InputStreamReader;
import java.nio.charset.StandardCharsets;
import java.util.ArrayList;
import java.util.List;

/**
 * Utility to parse CSV datasets with quote support.
 */
public class DatasetLoader {

    public static class Sample {
        public final String text;
        public final String label;

        public Sample(String text, String label) {
            this.text = text;
            this.label = label;
        }
    }

    public static List<Sample> loadCsvFromStream(InputStream inputStream) {
        List<Sample> samples = new ArrayList<>();
        try (BufferedReader reader = new BufferedReader(new InputStreamReader(inputStream, StandardCharsets.UTF_8))) {
            String line;
            boolean isHeader = true;

            while ((line = reader.readLine()) != null) {
                line = line.trim();
                if (line.isEmpty()) continue;
                if (isHeader) {
                    isHeader = false;
                    continue;
                }

                // Parse CSV with quoted text e.g. "I can't breathe",panic
                String text;
                String label;
                if (line.startsWith("\"")) {
                    int lastQuote = line.lastIndexOf("\"");
                    if (lastQuote > 0 && lastQuote < line.length() - 1) {
                        text = line.substring(1, lastQuote).replace("\"\"", "\"");
                        String remainder = line.substring(lastQuote + 1);
                        int commaIdx = remainder.indexOf(",");
                        if (commaIdx != -1) {
                            label = remainder.substring(commaIdx + 1).trim();
                        } else {
                            label = remainder.trim();
                        }
                    } else {
                        continue;
                    }
                } else {
                    int commaIdx = line.lastIndexOf(",");
                    if (commaIdx != -1) {
                        text = line.substring(0, commaIdx).trim();
                        label = line.substring(commaIdx + 1).trim();
                    } else {
                        continue;
                    }
                }

                if (!text.isEmpty() && !label.isEmpty()) {
                    samples.add(new Sample(text, label));
                }
            }
        } catch (Exception e) {
            System.err.println("Error reading CSV dataset: " + e.getMessage());
        }
        return samples;
    }
}

/**
 * Multinomial Logistic Regression (Softmax Regression) in Java.
 * Trained using Gradient Descent with Cross-Entropy Loss and L2 Regularization.
 * Evaluates full Accuracy, Precision, Recall, and F1 Score.
 */
public class LogisticRegressionClassifier implements Serializable {

    private static final long serialVersionUID = 1L;

    private List<String> classes = new ArrayList<>();
    private Map<String, Integer> classToIndex = new HashMap<>();

    private double[][] weights; // [numClasses][featureDim]
    private double[] biases;     // [numClasses]
    private int featureDim;

    // Hyperparameters
    private double learningRate = 1.2;
    private double l2Lambda = 0.00005;
    private int epochs = 400;

    public LogisticRegressionClassifier() {}

    public LogisticRegressionClassifier(double learningRate, double l2Lambda, int epochs) {
        this.learningRate = learningRate;
        this.l2Lambda = l2Lambda;
        this.epochs = epochs;
    }

    /**
     * Trains the model on labeled feature vectors.
     */
    public void train(double[][] X, List<String> y) {
        if (X == null || X.length == 0 || y == null || y.isEmpty()) {
            throw new IllegalArgumentException("Training data cannot be empty.");
        }

        int nSamples = X.length;
        this.featureDim = X[0].length;

        // Extract unique classes
        Set<String> uniqueClasses = new LinkedHashSet<>(y);
        this.classes = new ArrayList<>(uniqueClasses);
        this.classToIndex = new HashMap<>();
        for (int i = 0; i < classes.size(); i++) {
            classToIndex.put(classes.get(i), i);
        }

        int numClasses = classes.size();
        this.weights = new double[numClasses][featureDim];
        this.biases = new double[numClasses];

        // Convert string labels to target one-hot vectors
        int[] targets = new int[nSamples];
        for (int i = 0; i < nSamples; i++) {
            targets[i] = classToIndex.get(y.get(i));
        }

        // Gradient Descent with learning rate decay
        for (int epoch = 0; epoch < epochs; epoch++) {
            double currentLr = learningRate / (1.0 + 0.001 * epoch);

            for (int i = 0; i < nSamples; i++) {
                double[] x = X[i];
                int targetClass = targets[i];

                // Compute logits z_k = W_k . x + b_k
                double[] logits = new double[numClasses];
                double maxLogit = Double.NEGATIVE_INFINITY;
                for (int k = 0; k < numClasses; k++) {
                    double dot = 0.0;
                    for (int d = 0; d < featureDim; d++) {
                        dot += weights[k][d] * x[d];
                    }
                    logits[k] = dot + biases[k];
                    if (logits[k] > maxLogit) {
                        maxLogit = logits[k];
                    }
                }

                // Softmax with numerical stabilization
                double sumExp = 0.0;
                double[] probs = new double[numClasses];
                for (int k = 0; k < numClasses; k++) {
                    probs[k] = Math.exp(logits[k] - maxLogit);
                    sumExp += probs[k];
                }
                for (int k = 0; k < numClasses; k++) {
                    probs[k] /= sumExp;
                }

                // Gradient update
                for (int k = 0; k < numClasses; k++) {
                    double error = probs[k] - (k == targetClass ? 1.0 : 0.0);

                    // Update bias
                    biases[k] -= currentLr * error;

                    // Update weights with L2 regularization
                    for (int d = 0; d < featureDim; d++) {
                        if (x[d] != 0.0) { // sparse speedup
                            double grad = error * x[d] + l2Lambda * weights[k][d];
                            weights[k][d] -= currentLr * grad;
                        }
                    }
                }
            }
        }
    }

    /**
     * Predicts class label and probabilities for a feature vector.
     */
    public ClassificationResult predict(double[] x) {
        if (weights == null || x == null || x.length != featureDim) {
            return new ClassificationResult("neutral", 0.0, Collections.emptyMap());
        }

        int numClasses = classes.size();
        double[] logits = new double[numClasses];
        double maxLogit = Double.NEGATIVE_INFINITY;

        for (int k = 0; k < numClasses; k++) {
            double dot = 0.0;
            for (int d = 0; d < featureDim; d++) {
                dot += weights[k][d] * x[d];
            }
            logits[k] = dot + biases[k];
            if (logits[k] > maxLogit) {
                maxLogit = logits[k];
            }
        }

        double sumExp = 0.0;
        double[] probs = new double[numClasses];
        for (int k = 0; k < numClasses; k++) {
            probs[k] = Math.exp(logits[k] - maxLogit);
            sumExp += probs[k];
        }

        Map<String, Double> probMap = new LinkedHashMap<>();
        int bestIdx = 0;
        double bestProb = -1.0;

        for (int k = 0; k < numClasses; k++) {
            probs[k] /= sumExp;
            String className = classes.get(k);
            probMap.put(className, probs[k]);
            if (probs[k] > bestProb) {
                bestProb = probs[k];
                bestIdx = k;
            }
        }

        return new ClassificationResult(classes.get(bestIdx), bestProb, probMap);
    }

    /**
     * Evaluates model on test data and returns Accuracy, Precision, Recall, and F1 Score.
     */
    public ModelMetrics evaluate(double[][] X_test, List<String> y_test) {
        int nSamples = X_test.length;
        int numClasses = classes.size();

        int[][] confusionMatrix = new int[numClasses][numClasses];
        int correct = 0;

        for (int i = 0; i < nSamples; i++) {
            ClassificationResult result = predict(X_test[i]);
            Integer trueIdx = classToIndex.get(y_test.get(i));
            Integer predIdx = classToIndex.get(result.getLabel());

            if (trueIdx != null && predIdx != null) {
                confusionMatrix[trueIdx][predIdx]++;
                if (trueIdx.equals(predIdx)) {
                    correct++;
                }
            }
        }

        double accuracy = (double) correct / nSamples;

        // Calculate macro precision, recall, and F1 per class
        double sumPrecision = 0.0;
        double sumRecall = 0.0;
        double sumF1 = 0.0;
        Map<String, Double> classF1 = new LinkedHashMap<>();
        int evaluatedClasses = 0;

        for (int k = 0; k < numClasses; k++) {
            int tp = confusionMatrix[k][k];
            int fn = 0;
            int fp = 0;

            for (int j = 0; j < numClasses; j++) {
                if (j != k) {
                    fn += confusionMatrix[k][j];
                    fp += confusionMatrix[j][k];
                }
            }

            double precision = (tp + fp) == 0 ? 0.0 : (double) tp / (tp + fp);
            double recall = (tp + fn) == 0 ? 0.0 : (double) tp / (tp + fn);
            double f1 = (precision + recall) == 0.0 ? 0.0 : 2.0 * (precision * recall) / (precision + recall);

            classF1.put(classes.get(k), f1);
            sumPrecision += precision;
            sumRecall += recall;
            sumF1 += f1;
            evaluatedClasses++;
        }

        double macroPrecision = sumPrecision / evaluatedClasses;
        double macroRecall = sumRecall / evaluatedClasses;
        double macroF1 = sumF1 / evaluatedClasses;

        return new ModelMetrics(accuracy, macroPrecision, macroRecall, macroF1, nSamples, classF1);
    }

    public List<String> getClasses() {
        return classes;
    }

package com.milly.backend.ai.nlp;

import java.io.Serializable;
import java.util.*;

/**
 * TF-IDF (Term Frequency - Inverse Document Frequency) Vectorizer in Java.
 * Implements standard smooth IDF: idf(t) = ln((1 + N) / (1 + df(t))) + 1
 * Applies L2-normalization on resulting vectors for accurate cosine similarity and linear classification.
 */
public class TfidfVectorizer implements Serializable {

    private static final long serialVersionUID = 1L;

    private Map<String, Integer> vocabulary = new HashMap<>();
    private List<String> indexToWord = new ArrayList<>();
    private double[] idf;
    private int documentCount = 0;
    private final boolean useBigrams;
    private final int minDocFreq;

    public TfidfVectorizer() {
        this(true, 1);
    }

    public TfidfVectorizer(boolean useBigrams, int minDocFreq) {
        this.useBigrams = useBigrams;
        this.minDocFreq = minDocFreq;
    }

    /**
     * Learns vocabulary and IDF weights from training documents.
     */
    public void fit(List<String> documents) {
        this.documentCount = documents.size();
        Map<String, Integer> docFreq = new HashMap<>();

        // Count document frequency for each unique term per document
        for (String doc : documents) {
            List<String> tokens = useBigrams ? Tokenizer.tokenizeWithBigrams(doc) : Tokenizer.tokenize(doc);
            Set<String> uniqueTokens = new HashSet<>(tokens);
            for (String token : uniqueTokens) {
                docFreq.put(token, docFreq.getOrDefault(token, 0) + 1);
            }
        }

        // Build sorted vocabulary filtered by minimum document frequency
        vocabulary.clear();
        indexToWord.clear();
        int idx = 0;
        for (Map.Entry<String, Integer> entry : docFreq.entrySet()) {
            if (entry.getValue() >= minDocFreq) {
                vocabulary.put(entry.getKey(), idx++);
                indexToWord.add(entry.getKey());
            }
        }

        // Calculate smooth IDF: idf(t) = ln((1 + N) / (1 + df(t))) + 1
        int vocabSize = vocabulary.size();
        idf = new double[vocabSize];
        for (Map.Entry<String, Integer> entry : vocabulary.entrySet()) {
            String term = entry.getKey();
            int termIdx = entry.getValue();
            int df = docFreq.get(term);
            idf[termIdx] = Math.log((1.0 + documentCount) / (1.0 + df)) + 1.0;
        }
    }

    /**
     * Transforms a single document into an L2-normalized TF-IDF feature vector.
     */
    public double[] transform(String document) {
        int vocabSize = vocabulary.size();
        double[] vector = new double[vocabSize];
        if (vocabSize == 0 || document == null) {
            return vector;
        }

        List<String> tokens = useBigrams ? Tokenizer.tokenizeWithBigrams(document) : Tokenizer.tokenize(document);
        if (tokens.isEmpty()) {
            return vector;
        }

        // Term frequency counts
        Map<String, Integer> tf = new HashMap<>();
        for (String token : tokens) {
            tf.put(token, tf.getOrDefault(token, 0) + 1);
        }

        double docLen = tokens.size();
        for (Map.Entry<String, Integer> entry : tf.entrySet()) {
            String term = entry.getKey();
            Integer termIdx = vocabulary.get(term);
            if (termIdx != null) {
                // Sublinear / Normalized TF * IDF
                double termFrequency = entry.getValue() / docLen;
                vector[termIdx] = termFrequency * idf[termIdx];
            }
        }

        // L2 Normalization: v = v / sqrt(sum(v_i^2))
        double sumSq = 0.0;
        for (double v : vector) {
            sumSq += v * v;
        }

        if (sumSq > 0.0) {
            double norm = Math.sqrt(sumSq);
            for (int i = 0; i < vector.length; i++) {
                vector[i] /= norm;
            }
        }

        return vector;
    }

    /**
     * Transforms an entire list of documents.
     */
    public double[][] transformCorpus(List<String> documents) {
        double[][] matrix = new double[documents.size()][];
        for (int i = 0; i < documents.size(); i++) {
            matrix[i] = transform(documents.get(i));
        }
        return matrix;
    }

    /**
     * Computes cosine similarity between two normalized vectors: dot product.
     */
    public static double cosineSimilarity(double[] v1, double[] v2) {
        if (v1 == null || v2 == null || v1.length != v2.length) {
            return 0.0;
        }
        double dot = 0.0;
        for (int i = 0; i < v1.length; i++) {
            dot += v1[i] * v2[i];
        }
        return Math.max(0.0, Math.min(1.0, dot));
    }

    public int getVocabSize() {
        return vocabulary.size();
    }

    public Map<String, Integer> getVocabulary() {
        return vocabulary;
    }

    public List<String> getIndexToWord() {
        return indexToWord;
    }
}

/**
 * Text Preprocessing and Tokenization for MILLY NLP Pipeline.
 * Handles lowercasing, punctuation removal, word boundary splitting,
 * stop word consideration, and unigram/bigram token extraction.
 */
public class Tokenizer {

    private static final Pattern PUNCTUATION_PATTERN = Pattern.compile("[^a-zA-Z0-9\\s]");
    private static final Pattern WHITESPACE_PATTERN = Pattern.compile("\\s+");

    // Standard English stop words (retaining emotionally relevant words like 'not', 'can', 'cant', 'no')
    private static final Set<String> STOP_WORDS = new HashSet<>(Arrays.asList(
            "a", "about", "above", "after", "again", "all", "am", "an", "and", "any", "are", "as", "at",
            "be", "because", "been", "before", "being", "below", "between", "both", "by",
            "did", "do", "does", "doing", "down", "during", "each", "few", "for", "from", "further",
            "had", "has", "have", "having", "he", "her", "here", "hers", "herself", "him", "himself", "his",
            "how", "i", "if", "in", "into", "is", "it", "its", "itself", "me", "more", "most", "my", "myself",
            "of", "off", "on", "once", "only", "or", "other", "ought", "our", "ours", "ourselves", "out", "over", "own",
            "same", "she", "should", "so", "some", "such", "than", "that", "the", "their", "theirs", "them", "themselves",
            "then", "there", "these", "they", "this", "those", "through", "to", "too", "under", "until", "up",
            "very", "was", "we", "were", "what", "when", "where", "which", "while", "who", "whom", "why", "with",
            "you", "your", "yours", "yourself", "yourselves"
    ));

    /**
     * Cleans and tokenizes input text into a list of words.
     */
    public static List<String> tokenize(String text) {
        if (text == null || text.trim().isEmpty()) {
            return Collections.emptyList();
        }

        // 1. Lowercase
        String cleaned = text.toLowerCase();

        // 2. Normalize contractions (e.g. can't -> cant, i'm -> im)
        cleaned = cleaned.replace("'", "").replace("â€™", "");

        // 3. Replace non-alphanumeric with spaces
        cleaned = PUNCTUATION_PATTERN.matcher(cleaned).replaceAll(" ");

        // 4. Split by whitespace
        String[] tokens = WHITESPACE_PATTERN.split(cleaned.trim());

        List<String> result = new ArrayList<>();
        for (String t : tokens) {
            String token = t.trim();
            if (token.length() > 1) { // keep words longer than 1 character
                result.add(token);
            }
        }
        return result;
    }

    /**
     * Tokenizes with both unigrams and bigrams for enhanced context capture.
     */
    public static List<String> tokenizeWithBigrams(String text) {
        List<String> unigrams = tokenize(text);
        if (unigrams.isEmpty()) {
            return unigrams;
        }

        List<String> tokens = new ArrayList<>(unigrams);
        for (int i = 0; i < unigrams.size() - 1; i++) {
            tokens.add(unigrams.get(i) + "_" + unigrams.get(i + 1));
        }
        return tokens;
    }

    public static boolean isStopWord(String word) {
        return STOP_WORDS.contains(word.toLowerCase());
    }
}

            log.info("Loading PTSD Knowledge Base from knowledge_base.json...");
            ClassPathResource resource = new ClassPathResource("data/knowledge_base.json");
            try (InputStream is = resource.getInputStream()) {
                this.articles = objectMapper.readValue(is, new TypeReference<List<KnowledgeArticle>>() {});
            }

            if (articles.isEmpty()) {
                log.warn("Knowledge base is empty!");
                return;
            }

            // Create indexable document corpus combining title, keywords, summary, and content
            List<String> documents = new ArrayList<>();
            for (KnowledgeArticle article : articles) {
                StringBuilder doc = new StringBuilder();
                doc.append(article.getTitle()).append(" ");
                if (article.getKeywords() != null) {
                    doc.append(String.join(" ", article.getKeywords())).append(" ");
                }
                doc.append(article.getSummary()).append(" ");
                doc.append(article.getContent());
                documents.add(doc.toString());
            }

            // Fit vectorizer on knowledge base documents
            vectorizer.fit(documents);
            articleVectors = vectorizer.transformCorpus(documents);
            isReady = true;

            log.info("Successfully indexed {} PTSD knowledge articles with vocabulary size {}",
                    articles.size(), vectorizer.getVocabSize());

        } catch (Exception e) {
            log.error("Failed to load Knowledge Base: {}", e.getMessage(), e);
        }
    }

    /**
     * Retrieves the top K most relevant articles using cosine similarity.
     */
    public List<KnowledgeArticle> retrieveRelevant(String query, int topK) {
        if (!isReady || query == null || query.trim().isEmpty() || articles.isEmpty()) {
            return Collections.emptyList();
        }

        double[] queryVector = vectorizer.transform(query);

        List<ScoredArticle> scored = new ArrayList<>();
        for (int i = 0; i < articles.size(); i++) {
            double sim = TfidfVectorizer.cosineSimilarity(queryVector, articleVectors[i]);
            // Boost match if keywords directly match words in query
            double keywordBoost = calculateKeywordBoost(query, articles.get(i));
            double totalScore = sim * 0.7 + keywordBoost * 0.3;

            scored.add(new ScoredArticle(articles.get(i), totalScore));
        }

        // Sort descending by score
        scored.sort((a, b) -> Double.compare(b.score, a.score));

        List<KnowledgeArticle> results = new ArrayList<>();
        for (int i = 0; i < Math.min(topK, scored.size()); i++) {
            KnowledgeArticle original = scored.get(i).article;
            // Create shallow copy to set relevance score
            KnowledgeArticle copy = new KnowledgeArticle();
            copy.setId(original.getId());
            copy.setTitle(original.getTitle());
            copy.setCategory(original.getCategory());
            copy.setKeywords(original.getKeywords());
            copy.setSummary(original.getSummary());
            copy.setContent(original.getContent());
            copy.setCopingTechnique(original.getCopingTechnique());
            copy.setRelevanceScore(scored.get(i).score);
            results.add(copy);
        }

        return results;
    }

    private double calculateKeywordBoost(String query, KnowledgeArticle article) {
        if (article.getKeywords() == null || article.getKeywords().isEmpty()) {
            return 0.0;
        }
        String q = query.toLowerCase();
        int matches = 0;
        for (String kw : article.getKeywords()) {
            if (q.contains(kw.toLowerCase())) {
                matches++;
            }
        }
        return Math.min(1.0, (double) matches / Math.min(3, article.getKeywords().size()));
    }

    private static class ScoredArticle {
        final KnowledgeArticle article;
        final double score;

        ScoredArticle(KnowledgeArticle article, double score) {
            this.article = article;
            this.score = score;
        }
    }

    public List<KnowledgeArticle> getAllArticles() {
        return articles;
    }

            "cannot keep myself safe",
            "commit suicide",
            "suicide",
            "end it all",
            "overdose and die",
            "suicidal thoughts",
            "better off dead",
            "goodbye cruel world"
    );

    public SafetyCheckResult checkSafety(String text) {
        if (text == null || text.trim().isEmpty()) {
            return new SafetyCheckResult(false, null, null);
        }

        String normalized = text.toLowerCase()
                .replace("'", "")
                .replace("â€™", "")
                .replaceAll("\\s+", " ")
                .trim();

        for (String phrase : CRISIS_KEYWORDS) {
            if (normalized.contains(phrase)) {
                return new SafetyCheckResult(true, phrase, CRISIS_RESPONSE);
            }
        }

        return new SafetyCheckResult(false, null, null);
    }

import com.milly.backend.entity.Checkin;
import com.milly.backend.repository.CheckinRepository;
import com.milly.backend.repository.GroundingSessionRepository;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;

import java.time.format.DateTimeFormatter;
import java.util.*;

@RestController
@RequestMapping("/api")
@CrossOrigin(origins = "*")
public class DashboardController {

    private final CheckinRepository checkinRepository;
    private final GroundingSessionRepository groundingRepository;

    public DashboardController(CheckinRepository checkinRepository, GroundingSessionRepository groundingRepository) {
        this.checkinRepository = checkinRepository;
        this.groundingRepository = groundingRepository;
    }

    @GetMapping("/dashboard")
    public ResponseEntity<DashboardResponse> getDashboard() {
        DashboardResponse resp = new DashboardResponse();
        List<Checkin> checkins = checkinRepository.findByUserIdOrderByCreatedAtDesc(1L);
        long groundingCount = groundingRepository.countByUserId(1L);
        resp.setGroundingSessionsCount(groundingCount);

        if (checkins.isEmpty()) {
            resp.setCurrentMood("Calm");
            resp.setCurrentStress(3);
            resp.setCurrentSleep(7.0);
            resp.setWeeklyAverageStress(3.0);
            resp.setWeeklyAverageSleep(7.0);
            resp.setRecentCheckins(Collections.emptyList());

            List<DashboardResponse.DayPoint> defaultPoints = Arrays.asList(
                    new DashboardResponse.DayPoint("Mon", 4, 6.5),
                    new DashboardResponse.DayPoint("Tue", 5, 6.0),
                    new DashboardResponse.DayPoint("Wed", 4, 7.0),
                    new DashboardResponse.DayPoint("Thu", 3, 7.5),
                    new DashboardResponse.DayPoint("Fri", 5, 6.0),
                    new DashboardResponse.DayPoint("Sat", 4, 7.0),
                    new DashboardResponse.DayPoint("Sun", 3, 7.5)
            );
            resp.setWeeklyData(defaultPoints);
            resp.setDescriptiveInsight("Welcome to MILLY. Complete your first daily check-in to begin visualizing your stress and sleep trends.");
            return ResponseEntity.ok(resp);
        }

        Checkin latest = checkins.get(0);
        resp.setCurrentMood(latest.getMood());
        resp.setCurrentStress(latest.getStress());
        resp.setCurrentSleep(latest.getSleepHours());
        resp.setRecentCheckins(checkins.stream().limit(7).toList());

        // Calculate weekly metrics
        List<Checkin> weeklyList = checkins.stream().limit(7).toList();
        double totalStress = 0.0;
        double totalSleep = 0.0;
        int stressCount = 0;
        int sleepCount = 0;

        List<DashboardResponse.DayPoint> chartPoints = new ArrayList<>();
        DateTimeFormatter dayFormatter = DateTimeFormatter.ofPattern("EEE");

        // Reverse to show chronological order Mon -> Sun
        List<Checkin> chronological = new ArrayList<>(weeklyList);
        Collections.reverse(chronological);

        for (Checkin c : chronological) {
            String dayStr = (c.getCreatedAt() != null) ? c.getCreatedAt().format(dayFormatter) : "Day";
            chartPoints.add(new DashboardResponse.DayPoint(dayStr, c.getStress(), c.getSleepHours()));

            if (c.getStress() != null) {
                totalStress += c.getStress();
                stressCount++;
            }
            if (c.getSleepHours() != null) {
                totalSleep += c.getSleepHours();
                sleepCount++;
            }
        }

        double avgStress = stressCount > 0 ? Math.round((totalStress / stressCount) * 10.0) / 10.0 : 0.0;
        double avgSleep = sleepCount > 0 ? Math.round((totalSleep / sleepCount) * 10.0) / 10.0 : 0.0;
        resp.setWeeklyAverageStress(avgStress);
        resp.setWeeklyAverageSleep(avgSleep);
        resp.setWeeklyData(chartPoints);

        // Formulate non-diagnostic descriptive insight
        StringBuilder insight = new StringBuilder();
        insight.append(String.format("Your average stress this week was %.1f/10 across logged check-ins. ", avgStress));
        if (avgSleep > 0) {
            insight.append(String.format("Average reported sleep duration was %.1f hours. ", avgSleep));
        }
        if (avgStress >= 6.5) {
            insight.append("Your stress levels have been elevated recently. Remember to give yourself moments of rest and pacing. If you have concerns about recurring symptoms, consider discussing them with a qualified mental health professional.");
        } else {
            insight.append("Your metrics reflect steady resilience this week. Keep utilizing your grounding toolkit whenever unexpected triggers arise.");
        }
        resp.setDescriptiveInsight(insight.toString());

        return ResponseEntity.ok(resp);
    }
}

/**
 * PRIVATE JOURNAL REST CONTROLLER.
 * Strict architectural isolation: No AI service is injected or called in this controller.
 */
@RestController
@RequestMapping("/api/journal")
@CrossOrigin(origins = "*")
public class JournalController {

    private final JournalEntryRepository journalRepository;
    private final UserRepository userRepository;

    // Default prototype PIN: "1234"
    private static final String DEFAULT_PIN = "1234";

    public JournalController(JournalEntryRepository journalRepository, UserRepository userRepository) {
        this.journalRepository = journalRepository;
        this.userRepository = userRepository;
    }

    @PostMapping("/verify-pin")
    public ResponseEntity<Map<String, Object>> verifyPin(@RequestBody Map<String, String> payload) {
        String enteredPin = payload.get("pin");
        Map<String, Object> resp = new HashMap<>();

        Optional<User> userOpt = userRepository.findById(1L);
        String correctPin = userOpt.map(User::getPinHash).orElse(DEFAULT_PIN);

        if (enteredPin != null && enteredPin.equals(correctPin)) {
            resp.put("authenticated", true);
            resp.put("message", "PIN verified successfully.");
            return ResponseEntity.ok(resp);
        } else {
            resp.put("authenticated", false);
            resp.put("message", "Invalid PIN. Access denied.");
            return ResponseEntity.status(HttpStatus.UNAUTHORIZED).body(resp);
        }
    }

    @PostMapping("/set-pin")
    public ResponseEntity<Map<String, Object>> setPin(@RequestBody Map<String, String> payload) {
        String newPin = payload.get("pin");
        Map<String, Object> resp = new HashMap<>();

        if (newPin == null || newPin.length() < 4) {
            resp.put("success", false);
            resp.put("message", "PIN must be at least 4 digits.");
            return ResponseEntity.badRequest().body(resp);
        }

        User user = userRepository.findById(1L).orElse(new User("demo_user", DEFAULT_PIN));
        user.setPinHash(newPin);
        userRepository.save(user);

        resp.put("success", true);
        resp.put("message", "PIN updated successfully.");
        return ResponseEntity.ok(resp);
    }

    @GetMapping
    public ResponseEntity<List<JournalEntry>> getEntries() {
        return ResponseEntity.ok(journalRepository.findByUserIdOrderByCreatedAtDesc(1L));
    }

    @PostMapping
    public ResponseEntity<JournalEntry> createEntry(@RequestBody JournalRequest request) {
        JournalEntry entry = new JournalEntry(
                request.getTitle() != null ? request.getTitle() : "Untitled Entry",
                request.getContent() != null ? request.getContent() : "",
                request.getMoodTag() != null ? request.getMoodTag() : "Personal"
        );
        JournalEntry saved = journalRepository.save(entry);
        return ResponseEntity.ok(saved);
    }

    @PutMapping("/{id}")
    public ResponseEntity<JournalEntry> updateEntry(@PathVariable Long id, @RequestBody JournalRequest request) {
        Optional<JournalEntry> opt = journalRepository.findById(id);
        if (opt.isEmpty()) {
            return ResponseEntity.notFound().build();
        }
        JournalEntry entry = opt.get();
        if (request.getTitle() != null) entry.setTitle(request.getTitle());
        if (request.getContent() != null) entry.setContent(request.getContent());
        if (request.getMoodTag() != null) entry.setMoodTag(request.getMoodTag());
        entry.setUpdatedAt(LocalDateTime.now());
        return ResponseEntity.ok(journalRepository.save(entry));
    }

    @DeleteMapping("/{id}")
    public ResponseEntity<Map<String, Object>> deleteEntry(@PathVariable Long id) {
        journalRepository.deleteById(id);
        Map<String, Object> resp = new HashMap<>();
        resp.put("success", true);
        resp.put("message", "Journal entry deleted.");
        return ResponseEntity.ok(resp);
    }

package com.milly.backend;

import com.milly.backend.controller.ChatController;
import com.milly.backend.dto.ChatRequest;
import com.milly.backend.dto.ChatResponse;
import org.junit.jupiter.api.DisplayName;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.context.SpringBootTest;
import org.springframework.http.ResponseEntity;

import static org.junit.jupiter.api.Assertions.*;

@SpringBootTest
class BackendApplicationTests {

	@Autowired
	private ChatController chatController;

	@Test
	@DisplayName("Context Loads Successfully")
	void contextLoads() {
		assertNotNull(chatController);
	}

	@Test
	@DisplayName("Scenario 1: Flashback detection")
	void testScenario1Flashback() {
		ResponseEntity<ChatResponse> resp = chatController.chat(new ChatRequest("I keep remembering what happened", "test-session-1"));
		assertNotNull(resp.getBody());
		ChatResponse body = resp.getBody();
		assertEquals("flashback", body.getIntent());
		assertFalse(body.isCrisis());
		assertEquals("grounding", body.getRecommendedAction());
	}

	@Test
	@DisplayName("Scenario 2: Nightmare and sleep distress")
	void testScenario2Nightmare() {
		ResponseEntity<ChatResponse> resp = chatController.chat(new ChatRequest("I can't sleep because I keep having nightmares.", "test-session-2"));
		assertNotNull(resp.getBody());
		ChatResponse body = resp.getBody();
		assertTrue(body.getIntent().equals("nightmare") || body.getIntent().equals("sleep_problem"));
		assertFalse(body.isCrisis());
	}

	@Test
	@DisplayName("Scenario 3: Sensory trigger detection")
	void testScenario3Trigger() {
		ResponseEntity<ChatResponse> resp = chatController.chat(new ChatRequest("Loud noises suddenly make me terrified.", "test-session-3"));
		assertNotNull(resp.getBody());
		ChatResponse body = resp.getBody();
		assertEquals("trigger", body.getIntent());
		assertEquals("fear", body.getEmotion());
		assertEquals("grounding", body.getRecommendedAction());
	}

	@Test
	@DisplayName("Scenario 4: Educational PTSD information request")
	void testScenario4Information() {
		ResponseEntity<ChatResponse> resp = chatController.chat(new ChatRequest("What exactly is PTSD?", "test-session-4"));
		assertNotNull(resp.getBody());
		ChatResponse body = resp.getBody();
		assertEquals("ptsd_information", body.getIntent());
		assertFalse(body.isCrisis());
		assertFalse(body.getRetrievedTopics().isEmpty());
	}

	@Test
	@DisplayName("Scenario 5: Grounding and panic assistance")
	void testScenario5Grounding() {
		ResponseEntity<ChatResponse> resp = chatController.chat(new ChatRequest("Help me calm down.", "test-session-5"));
		assertNotNull(resp.getBody());
		ChatResponse body = resp.getBody();
		assertTrue(body.getIntent().equals("grounding") || body.getIntent().equals("panic"));
		assertTrue(body.getRecommendedAction().equals("grounding") || body.getRecommendedAction().equals("breathing"));
	}

	@Test
	@DisplayName("Scenario 6: Crisis detection and safety response")
	void testScenario6Crisis() {
		ResponseEntity<ChatResponse> resp = chatController.chat(new ChatRequest("I don't want to live anymore.", "test-session-6"));
		assertNotNull(resp.getBody());
		ChatResponse body = resp.getBody();
		assertTrue(body.isCrisis());
		assertEquals("crisis", body.getIntent());
		assertEquals("emergency", body.getRecommendedAction());
		assertTrue(body.getResponse().contains("immediate human support") || body.getResponse().contains("emergency services"));
	}
}

  const filterNodeRef = useRef(null);
  const sourceNodeRef = useRef(null);
  const timerRef = useRef(null);

  const initAudio = () => {
    if (!audioCtxRef.current) {
      const AudioCtx = window.AudioContext || window.webkitAudioContext;
      audioCtxRef.current = new AudioCtx();
    }
    if (audioCtxRef.current.state === 'suspended') {
      audioCtxRef.current.resume();
    }
  };

  const startSound = () => {
    initAudio();
    stopSound();

    const ctx = audioCtxRef.current;
    const bufferSize = ctx.sampleRate * 4; // 4 seconds of noise buffer
    const buffer = ctx.createBuffer(1, bufferSize, ctx.sampleRate);
    const data = buffer.getChannelData(0);

    // Generate warm brown/pink noise
    let lastOut = 0.0;
    for (let i = 0; i < bufferSize; i++) {
      const white = Math.random() * 2 - 1;
      // Brown noise integration filter
      lastOut = (lastOut + 0.02 * white) / 1.02;
      data[i] = lastOut * 3.5;
    }

    const noise = ctx.createBufferSource();
    noise.buffer = buffer;
    noise.loop = true;

    // Filter node
    const filter = ctx.createBiquadFilter();
    if (soundType === 'rain') {
      filter.type = 'lowpass';
      filter.frequency.setValueAtTime(900, ctx.currentTime);
    } else if (soundType === 'brown') {
      filter.type = 'lowpass';
      filter.frequency.setValueAtTime(450, ctx.currentTime);
    } else {
      // Ocean waves: lower cutoff, will be modulated
      filter.type = 'lowpass';
      filter.frequency.setValueAtTime(500, ctx.currentTime);
    }

    const gain = ctx.createGain();
    gain.gain.setValueAtTime(volume, ctx.currentTime);

    noise.connect(filter);
    filter.connect(gain);
    gain.connect(ctx.destination);

    noise.start();

    sourceNodeRef.current = noise;
    filterNodeRef.current = filter;
    gainNodeRef.current = gain;

    // Ocean waves rhythmic oscillation
    if (soundType === 'ocean') {
      let phase = 0;
      timerRef.current = setInterval(() => {
        if (!filterNodeRef.current || !gainNodeRef.current) return;
        phase += 0.06;
        // Natural ebb and flow
        const freq = 400 + Math.sin(phase) * 280;
        const vol = volume * (0.6 + Math.sin(phase) * 0.35);
        filterNodeRef.current.frequency.setTargetAtTime(Math.max(120, freq), ctx.currentTime, 0.1);
        gainNodeRef.current.gain.setTargetAtTime(Math.max(0.01, vol), ctx.currentTime, 0.1);
      }, 100);
    }

    setIsPlaying(true);
  };

  const stopSound = () => {
    if (timerRef.current) {
      clearInterval(timerRef.current);
      timerRef.current = null;
    }

      try {
        sourceNodeRef.current.stop();
        sourceNodeRef.current.disconnect();
      } catch (e) {}
      sourceNodeRef.current = null;
    }
    setIsPlaying(false);
  };

    if (isPlaying) {
      startSound();
    }
    return () => stopSound();
